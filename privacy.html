Privacy Policy

Effective date: October 23, 2026

lifehub is a personal application that Yu Xing (the "owner") operates for their own use. The only person whose Google account lifehub accesses is the owner.

Data lifehub accesses

With the owner's explicit consent through Google OAuth, lifehub requests the read-only scope https://www.googleapis.com/auth/drive.readonly. With it, lifehub can read the owner's Google Drive file metadata (such as names, folders, types and timestamps) and file contents.

How lifehub uses the data

lifehub uses this data only to index, categorize and search the owner's own documents, and to answer the owner's own questions about them. lifehub does not use the data for advertising, does not build profiles of anyone other than the owner, and does not sell the data.

Storage

lifehub stores the OAuth tokens and any data it reads on the owner's own computer. It does not run a server and does not upload Google user data to any server that the owner does not control.

Sharing

lifehub does not share Google user data with third parties. The owner may choose to process their own data with tools they use personally, such as AI assistants. That happens only at the owner's direction and only for the owner's own purposes.

Limited Use

lifehub's use and transfer of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

Retention and deletion

The owner can delete all locally stored data and tokens at any time. The owner can also revoke lifehub's access at any time at myaccount.google.com/permissions. After access is revoked, lifehub can no longer read any Google data.

Changes

If this policy changes, the updated version will be posted on this page with a new effective date.
