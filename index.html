lifehub

A personal, single-user data hub

lifehub is a private tool that Yu Xing built for personal use. It collects the owner's own data from services the owner uses, organizes it on the owner's own computer, and produces personal summaries and reminders.

lifehub is not a public service. No one other than the owner can sign up for it or use it.

Google integration

lifehub uses Google OAuth to access the owner's own Google account:

  • Google Drive, read-only (https://www.googleapis.com/auth/drive.readonly): reads file metadata and content to index and categorize the owner's documents. It never creates, modifies, shares or deletes anything in Google Drive.
  • Gmail, read-only (https://www.googleapis.com/auth/gmail.readonly): reads the owner's messages to search them and answer the owner's questions.
  • Gmail drafts and sending (https://www.googleapis.com/auth/gmail.compose): creates draft emails, and sends a draft only after the owner explicitly approves that specific draft. It does not delete messages or change labels.
